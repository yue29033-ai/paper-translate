# 翻译与版面审核

审核对象是本次选定的全部内容。全文任务须覆盖全部原文页和全部输出页；只有选定页的样例不能证明全文质量。机器检查与人工/Agent 审核分别记录，未完成的项目不得表述为通过。

## 语义与术语

- 逐块对读原文和译文，确认完整命题、条件、比较对象、限定范围与结论。相同字符数、句数或有中文填入，均不能证明语义完整。
- 保留论证强度：`may`、`suggest`、`is associated with` 不可升级为“证明”“导致”或“必然”；`significantly` 结合统计语境翻译，不能随意添加“显著”。
- 核对否定、双重否定、例外和转折：`not`、`unless`、`without`、`whereas` 等词很容易在重组句子时丢失。明确谁在什么条件下发生了什么变化。
- 数字、正负号、小数点、百分数、科学计数法、单位、样本量、误差类型、置信区间、P 值、上下标和统计符号逐项保真；数值不因中文习惯而换算或圆整。
- 保留引文序号、作者年份、图号、分图字母、表号、补充材料号及其对应关系。`Fig. 2a–c` 不能合并为无分图定位的“图 2”。
- 术语首次出现附英文，后文按 `glossary` 使用；标题或正文对同一概念的译法应一致，确有不同含义时在术语表区分语境。
- 基因/蛋白名称、等位基因、品系、突变体、物种、构建体和数据库编号不凭读音改写。核对容易混淆的 `1/l/I`、`0/O`、连字符、希腊字母及大小写。
- 图注与表注保留处理组、缩写定义、颜色说明、统计方法、样本量、标尺和显著性标记的解释；图内标签仍沿用原文。
- 不把研究者的推测改成事实，不把文献转述改成本文结果，不把体外、温室、田间或某个品种中的结果泛化到更广范围。
- 对源文疑似错误和不可辨认文字记录页码、块 ID 及问题，不静默修订成自认为正确的事实；必要的校勘说明与论文译文分开。

## 分区、阅读顺序与续句

- 双栏论文按真实阅读顺序重排。跨栏标题、浮动图表和旁注可能让提取顺序错误，必须对照原页确定。
- 检查 `translate` 文本是否误含图内标签、坐标或公式片段；保留区内文字只作审核信息，不应再翻译一次。
- 保留区边界包含分图字母、图例、轴标签、标尺和公式编号。不要仅以某个栅格图片对象的矩形代表整幅图。
- 表格主体作为一个原文区域保留，包括行列标题、单元格文字及脚注符号；表题与表下说明性注释（表注）单独翻译。分区时检查表注位置，避免误裁进保留区造成重复或漏译。
- 跨页续句先连读再翻译，译文在各源页锚点之间只出现一次。续页后的指代、主语和限定条件不得因分段而改变。
- 首次术语的英文括注不需要在每个分页重复；图注中为自足阅读保留的缩写定义按原文完整译出。
- 正文中的公式要保留原 PDF 内容；将前后文字拆成可翻译块并正确排序。不得保留完整英文正文来规避公式分离，也不得重绘或猜写不确定公式。
- 扫描件 OCR 必须逐页对照图像。低置信度片段、损坏字体映射或公式 OCR 错误须解决或明确保持未完成，不能把错误提取文本当作可靠原文。

## 视觉审核

逐页查看中文版和对照版，检查下列实际结果：

| 检查 | 通过条件 |
|---|---|
| 中文文本 | 可读、可搜索；无方框缺字、叠字、裁切、乱码、重复段落和异常空白 |
| 图、表和公式 | 内容完整；图内文字和矢量线条保留；比例合理且足以阅读，无文字覆盖 |
| 图文关联 | 图注/表注紧邻对应图表，图号和分图定位一致，阅读顺序清楚 |
| 页面归属 | 每一源页的中文内容独立成组；续页不混入下一源页文本 |
| 左右对照 | 左中文与右侧原文同源页，右侧为完整页面且清晰；续页重复正确原文并注明关系 |
| 保留信息 | 作者机构、DOI、链接、参考文献及既定省略规则准确，没有为了排版遗漏正文 |

不要用“原文件哈希未变”推断译稿保留区完整；它只证明源文件未被改写。保留区渲染比对可以证明对应渲染内容是否相同，仍需视觉判断裁切范围是否本来就漏掉图例或标签。

遇到空间不足，优先续页，再考虑轻微调整字号与间距；大图可独占页。整图、整表不能裁成难以匹配的碎片。中文字流与保留区须有清楚间隔。

## 审核记录与完成声明

- `page.reviewed=true`：已对照渲染原页确认该页区域与顺序；不表示翻译或成品视觉已通过。
- `review.translation_checked=true`：本次范围全部翻译块已逐段完成语义、术语、数字和引用核对。
- `review.visual_checked=true`：本次范围两份 PDF 的全部输出页已查看，发现的问题已修正。
- 有未解问题时保留在 `warnings` 或审核说明中，保持对应标志为 false。不能把缺少检查的人为置真当作消除报错的方法。
- 修改译文后重新审核受影响语义；修改排版后重新审核受影响页面。内容或结构改变会使旧的机器报告失效，应重新生成和验证。
- 检查报告应明确实际选定源页、覆盖范围、机器执行项目及结果、审核标志、未解决问题。以脚本实际产出的结果为准，不补写没有运行过的检查。

最终表述与证据匹配：`ready` 的节选称“选定 X 页样例完成”；所有源页均被处理且最终验证通过，才可称“全文完成”。未解决提取或翻译问题的文件仅作为有明确标记的草稿交付。
